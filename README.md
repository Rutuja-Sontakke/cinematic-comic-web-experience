🕷️ Cinematic Comic Web Experience

A cinematic Spider-Gwen inspired portfolio experience built with React and TypeScript, combining comic-book visuals, scroll-driven storytelling, parallax, glitch effects, and interactive animations.

LIVE DEMO:  https://spiderwomenverse.vercel.app/

✨ Features
🎬 Scroll-driven cinematic scenes
🕸️ Comic-style visual design
🌆 Animated city/parallax backgrounds
🎨 Gwenverse-inspired neon color palette
⚡ Glitch & motion effects
🖱️ Custom interactive cursor
📱 Responsive design
🎭 Story-driven section transitions
🛠️ Tech Stack

React · TypeScript · Vite · CSS · SVG · Framer-style motion techniques

🚀 Run Locally
npm install
npm run dev
